# Agents

This is my personal wiki. The schema is `README.md`; everything you do here follows it.

1. `git pull --ff-only` before anything else. One writer at a time.
2. Read `README.md` in full.
3. Read `INDEX.md`. Open only the pages the task needs. Never bulk-read `wiki/` or `journal/`.
4. Before diagnosing, deciding or configuring anything mid-task, re-check `INDEX.md` for a page that already covers it, and say which page you used.
5. Never write a secret down. If I paste one, tell me.
6. I give instructions in natural language. "Update the wiki" or similar means the session-end pass in `skills/wiki-update/SKILL.md`: named pages, lint, one commit, push. "Lint the wiki" means `skills/wiki-lint/SKILL.md`.
7. This repo has no connection to any other wiki or skill set. If I type `/wiki-update`, `/wiki-lint` or any other slash command that names a wiki while working here, do not run it: it belongs to a different wiki. Say so and stop.
